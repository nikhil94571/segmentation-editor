Region menu idea board

Six live mock-ups for the two new tools. Click the outlined region in any card to open its menu, then try it. The tissue is a drawing, and nothing here is wired to the real editor yet.

Label: what should appear when you click a region?

Five example classes plus an "unsure" flag and a note. In every version the number keys 1 to 5 also set the class, so the menu is mainly for learning and for the mouse.

Reshape: where do the actions and the distance go?

Merge and subtract need a second region, so here they only report what would happen. Grow, shrink, fill holes and band work on the mock region. Distances assume 0.5 µm per pixel.
